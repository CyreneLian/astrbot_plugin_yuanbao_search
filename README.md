# 🌸 元宝搜索插件 (`astrbot_plugin_yuanbao_search`)

为 **AstrBot** 提供每月 2000 次的免费腾讯生态实时联网检索能力。基于腾讯云元宝搜索（wsa / SearchPro）接口，支持网页信源、优质权威垂直信源、混合结果，并可按站点、垂直领域与时间范围精细过滤，可以让 Bot 在回答中获取实时外部信息。并**支持大模型工具**（`yuanbao_search`），大模型可直接理解用户的自然语言检索诉求并自动调用，无需记忆指令格式。

---

## ✨ 核心特性

1. **单工具覆盖搜索全流程**：
   - `yuanbao_search`：一个工具同时完成「找链接 + 读正文 + 精过滤」，无需像其它方案那样再单独调用正文提取工具。
2. **三种信源模式自由切换**：
   - `mode=0`：公开网页信源结果（默认），覆盖全网公开资源。
   - `mode=1`：优质权威垂直信源结果，优先命中政府、学术、财经等高权威度来源。
   - `mode=2`：混合结果，在网页信源基础上额外补充权威垂直信源。
3. **精细化过滤能力**：
   - `site`：指定网址搜索（单个域名）或网址过滤（`exclude:域名1|域名2`，最多排除五个域名）。
   - `industry`：垂直领域搜索，支持 `gov` 政府、`news` 新闻、`acad` 学术、`finance` 财经。
   - `freshness`：搜索时效范围，支持 `d7` 最近七天、`m3` 最近三月、`y2` 最近两年，或 `yyyy-mm-dd,yyyy-mm-dd` 日期区间。
4. **摘要长度两档可调**：
   - 默认返回标准摘要（约 800 字），信息足够时开箱即用。
   - `full_content=true` 返回动态摘要（单条上限约 2500 字），含更完整的正文细节。
   - `max_chars` 可手动控制单条摘要字数上限，防止大模型上下文被撑爆。
5. **零第三方依赖**：仅用标准库 + aiohttp，TC3-HMAC-SHA256 签名自实现，无需安装腾讯云 SDK。

## 🚀 大模型工具使用方法与指令范例

插件注册了 `yuanbao_search` 工具，大模型会在需要实时资料时自动调用；也可以直接用自然语言要求进行查询。

### 工具参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `query` | string | 必填。搜索关键词或自然语言问题。 |
| `mode` | int | 返回结果类型。`0` 公开网页信源（默认）、`1` 优质权威垂直信源、`2` 混合结果。 |
| `site` | string | 指定网址搜索或过滤。指定搜索填单个域名如 `zhihu.com`；过滤用 `exclude:域名1\|域名2`，最多五个域名。 |
| `cnt` | int | 返回结果条数，可填 `10`/`20`/`30`/`40`/`50`，默认 `10`。 |
| `industry` | string | 垂直领域搜索，可填 `gov` 政府、`news` 新闻、`acad` 学术、`finance` 财经。 |
| `freshness` | string | 搜索时效范围，可填 `d7` 最近七天、`m3` 最近三月、`y2` 最近两年，或具体日期区间如 `2026-08-20,2026-08-30`。 |
| `full_content` | boolean | 是否返回更详细的正文摘要。默认 `false` 返回标准摘要约 800 字；设为 `true` 返回动态摘要约 2000 字。 |
| `max_chars` | int | 单条结果的摘要字数上限，`0` 表示不限制（默认）。注意接口本身单条摘要上限约 2500 字，本参数只能做截断不能突破接口上限。 |

### 指令范例

| 指令 | 说明 |
| --- | --- |
| `/元宝搜索 崩坏星穹铁道 4.6 版本` | 基础搜索，返回 10 条结果 |
| `/元宝搜索 今日人工智能新闻 mode=2` | 混合信源模式，兼顾网页与权威来源 |
| `/元宝搜索 人工智能产业报告 industry=news freshness=d7 cnt=20` | 指定新闻领域、最近七天、20 条结果 |
| `/元宝搜索 昔涟 剧情解析 site=zhihu.com` | 只搜索知乎域名下的内容 |
| `/元宝搜索 天气 site=exclude:qq.com\|sohu.com` | 排除 qq.com 与 sohu.com 两个域名 |
| `/元宝搜索 编程教程 full_content=true` | 指令同样支持参数，直接拿更详细的正文摘要 |

> **提示**：指令支持以 `key=value` 形式附加检索策略，参数顺序不限；未识别的参数会安全忽略。

> **提示**：指令别名还包括 `/元宝`、`/元宝搜` 与英文 `/yuanbao`。

## ❓ 常见问题 (FAQ)

**Q: 为什么单条摘要最多只有约 2500 字，能手动开更大吗？**

A: 元宝接口的入参只有 `Query` / `Mode` / `Site` / `Cnt` / `Industry` / `Freshness` / `Deeplinks`，**没有任何参数能控制单条摘要长度**，长度由服务端按查询内容自适应决定，实测天花板约 2500 字。需要更多内容时应调整策略：① 打开 `full_content=true`（800 → 2500 字）；② 调大 `cnt`（`cnt=50` 时总量可从约 1.9 万字涨到约 8.7 万字）；③ 换更精确的关键词；④ 用 `max_chars` 主动截断控制总量。

**Q: 用 `site=zhihu.com` 搜索为什么会返回 0 条？**

A: 这是接口自身的过滤行为，不是插件故障。指定域名搜索时，结果必须来自该域名，若该域名下确实没有匹配内容就会返回空。可改用 `mode=2` 混合模式放宽范围，或直接去掉 `site` 参数做全网搜索。

**Q: 搜索结果显示「元宝搜索未返回结果」怎么办？**

A: 依次检查：① 配置面板中的 `secret_id` 与 `secret_key` 是否都已填写；② 腾讯云账号是否已开通元宝搜索服务（否则会返回 `ResourceNotFound`）；③ 搜索词是否过于具体，可换更通用的关键词重试；④ 免费额度是否耗尽。

> **提示**：若账号下没有元宝搜索服务，可前往腾讯云官网 https://cloud.tencent.com 搜索「元宝搜索」进入控制台免费开通后再使用。
